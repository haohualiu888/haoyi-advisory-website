## Review Checklist

Before adding any future government, hospital, university, industrial park, or named public institution:

1. Confirm the source is official or clearly attributable.
2. Confirm the image is real and has a recorded source URL.
3. Avoid claiming a relationship unless there is explicit approval to publish it.
4. Mark uncertain project eligibility, subsidies, clinical access, or policy benefits as `To be confirmed`.
5. Commit the source update with the website code and let Vercel deploy from GitHub.
